## Layout
- Desktop-first layout that collapses gracefully to mobile.
- Generous whitespace.
- Left navigation on desktop; compact menu on mobile.

## Navigation
- Desktop navigation includes Notes and Archived.
- Desktop navigation includes the user's tag list underneath.
- Mobile navigation uses a compact menu.
- Sign in and Sign up are separate focused screens linked to each other.

## Tables and lists
- Use a quiet notes list rather than a dashboard-style layout.

## Charts
- No charts.

## Tone
- Clean, minimal, calm productivity tool.
- Quiet notebook feel, not a dashboard.
- Neutral palette with one soft indigo accent.
- Readable sans-serif for UI and note text.
- Support light and dark themes.
- Follow the device theme by default.
- Provide a manual theme switch in the app header.
